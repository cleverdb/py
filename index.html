一年级拼音学习微信小程序的音频托管目录 · GitHub Pages

本页为音频托管自检页（mock），用于核对全部音频是否可访问、试听发音，非小程序产品界面。

准备中…

小程序接入：把 AUDIO_BASE（app/utils/audio.js）与 SPELL_AUDIO_BASE（app/pages/quiz/quiz.js）指向本 Pages 目录，并在微信公众平台把 https://cleverdb.github.io 加入 downloadFile 合法域名。注意 GitHub Pages 域名在国内通常未 ICP 备案，后台可能拒绝保存；若被拒需绑定自有已备案域名（CNAME）。

文件名规则：spell-audio/ 为去调音节 + 调号（bà→ba4.m4a，ü 写作 v）；audio-host/quiz/ 以题目 id 命名，其余按拼音/示例词/声调/音效/引导分类。清单为构建时快照，共 — 条。
